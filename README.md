# 책잎 — 나의 독서 기록

월별로 읽은 책을 한눈에 모아보고, 책마다 인상 깊었던 부분과 한줄 감상, 별점을 남길 수 있는 2026년 독서 기록 앱입니다. 읽은 책이 늘어날수록 연간 독서량과 평균 별점, 독서 정원의 성장 메시지가 함께 바뀝니다.

**배포 주소:** [책잎 열기](https://book-leaf-records-2026.okidokiyo0317.chatgpt.site/)

## 주요 기능

- **월별 책장**: 1월부터 12월까지 월을 선택해 읽은 책을 구분하여 확인할 수 있습니다.
- **독서 기록 추가**: 책 제목, 지은이, 읽은 달, 별점, 인상 깊었던 부분과 한줄 감상을 기록합니다.
- **5점 별점**: 책마다 1점부터 5점까지 별점을 매길 수 있습니다.
- **기록 수정과 삭제**: 책 카드를 누르면 작성한 내용을 다시 열어 수정하거나 삭제할 수 있습니다.
- **연간 독서 요약**: 올해 읽은 책의 수와 평균 별점을 자동으로 계산합니다.
- **자동 저장**: 작성한 기록을 브라우저의 `localStorage`에 저장해 새로고침 후에도 유지합니다.
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 화면 크기에 맞춰 책장과 입력창이 조정됩니다.
- **접근성 지원**: 키보드로 책 카드를 열 수 있으며, 버튼과 입력 요소에 접근성 레이블을 제공합니다.

## 사용 방법

1. 상단의 `책 기록하기` 버튼이나 책장의 `이달의 책 추가하기`를 누릅니다.
2. 책 제목과 읽은 달을 입력하고 별점을 선택합니다.
3. 기억하고 싶은 문장이나 장면을 `인상 깊었던 부분`에 기록합니다.
4. 책을 기억할 수 있는 짧은 감상을 작성한 뒤 `책장에 꽂기`를 누릅니다.
5. 월별 탭을 누르면 해당 월에 읽은 책만 모아서 볼 수 있습니다.
6. 기존 책 카드를 누르면 기록을 수정하거나 삭제할 수 있습니다.

프레임워크나 별도의 빌드 도구 없이 정적 HTML, CSS, JavaScript로 구성되어 있습니다.

## 디자인

- 메인 컬러: 연두색
- 폰트: `OngleipParkDahyeon`
- 둥근 모서리와 손으로 그린 듯한 테두리, 부드러운 그림자를 사용한 귀여운 기록장 스타일
- 책 제목을 기준으로 카드 색상을 자동 배정하여 월별 책장을 구분하기 쉽게 구성

웹폰트는 아래 CDN 주소에서 불러옵니다.

```css
@font-face {

  font-weight: normal;

}
```

## 로컬 실행

Node.js가 설치된 환경에서 이 폴더로 이동한 뒤 정적 서버를 실행합니다.

```bash
npx serve dist
```

터미널에 표시되는 로컬 주소를 브라우저에서 열면 됩니다. `dist/index.html`을 직접 열 수도 있지만, 브라우저 환경에 따라 일부 기능이 제한될 수 있으므로 로컬 서버 사용을 권장합니다.

## 데이터 저장 방식

독서 기록은 서버나 사용자 계정이 아니라 현재 브라우저에만 저장됩니다.

- 같은 브라우저에서 새로고침해도 기록이 유지됩니다.
- 다른 기기나 다른 브라우저에는 기록이 자동으로 동기화되지 않습니다.
- 브라우저의 사이트 데이터 또는 저장 공간을 삭제하면 기록도 함께 삭제됩니다.

저장에 사용하는 키는 `book-leaf-records-v1`입니다.

## WebMCP 지원

호환되는 환경에서는 다음 도구를 통해 독서 기록을 다룰 수 있습니다.

- `add_book_record`: 지정한 월에 책 제목, 별점, 인상 깊은 부분과 감상을 추가합니다.
- `list_book_records`: 지정한 월에 기록된 책 목록을 조회합니다.

## 브라우저 지원

최신 버전의 Chrome, Edge, Safari, Firefox 사용을 권장합니다. `localStorage`와 `<dialog>`를 지원하는 브라우저가 필요합니다.
